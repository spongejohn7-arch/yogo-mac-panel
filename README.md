# YOGO Mac Panel

用于 **ATK YOGO 75 PRO** 6×6 像素屏的 macOS 中文控制面板。
支持图片、纯色、文字、动画，以及本地 Codex 工作状态联动。

> 本项目是 [rossgpt/yogo](https://github.com/rossgpt/yogo) 的独立界面扩展。
> USB 通信、基础帧处理、字体和简洁灯效由该 MIT 开源项目提供；感谢原作者的协议研究与实现。
> 这是社区项目，与 ATK、OpenAI 和原作者均无官方隶属或背书关系。

## 功能

- 浏览器中文界面，上传图片并预览 6×6 像素效果，图片在浏览器本地处理。
- 纯色、亮度、彩虹、英文字母与数字逐字显示。
- Codex 本地事件跟随：工作、工具调用、完成、错误、明确记录的等待事件。
- 四个主题：小机器人、像素花园、太空任务、简洁灯效。
- 停止并恢复键盘原厂显示；所有效果采用实时推送，不保存到键盘闪存。

## 环境要求

- macOS，Python **3.10 或更新版本**，以及 [Homebrew](https://brew.sh)。
- ATK YOGO 75 PRO，通过 **USB 数据线或 2.4G 接收器**连接，并切换到对应档位。
- 退出 ATK HUB、上游 yogo daemon 或其他占用键盘的控制程序。
- Codex 联动需要这台 Mac 上有可读取的 `~/.codex/sessions` 本地会话文件。

已在一台 Apple 芯片 Mac 和 YOGO 75 PRO 上验证 USB 连接，以及 2.4G 握手和小屏推送回应。
Intel Mac 尚未实机验证；不支持蓝牙控制小屏。
面板自动选择有回应的连接；断线后自动重试。2.4G 动画最高约 5 帧/秒，以降低无线通信负担。

## 安装

先安装 Python 与 HIDAPI：

```sh
brew install python hidapi
```

下载本仓库到希望长期保留的位置，进入目录后运行：

```sh
bash install.sh
```

如果系统的 `python3` 版本过旧，可明确使用 Homebrew Python：

```sh
YOGO_PYTHON="$(brew --prefix)/bin/python3" bash install.sh
```

脚本会在本目录建立独立 `.venv`，安装固定版本的上游依赖，并生成
`~/Applications/YOGO Mac Panel.app`。它不安装 Codex 插件、不修改 Codex 配置。
如果同名启动器已存在，脚本不会覆盖它。移动仓库后，使用新目录的
`start.command`；需要重建启动器时先在 Finder 中移走旧启动器。

## 打开与使用

双击 `start.command` 或 `YOGO Mac Panel.app`。服务运行后，也可打开：

**http://127.0.0.1:18765**

- 图片、纯色、彩虹、文字：选择内容和亮度，点击“显示到键盘”。
- Codex：切换到 Codex 页签，点击“开启 / 应用联动”。
- 主题：在 Codex 页签选择主题，立即应用并开启联动。
- “停止 / 恢复原厂”：关闭当前效果并交回屏幕控制权。
- “熄灭小屏”：持续推送黑色画面。

关闭网页后，后台服务和效果仍会运行。退出前可先点击“停止 / 恢复原厂”。
重启电脑后需重新启动面板并开启联动。使用“活动监视器”退出本项目 Python
服务也能结束后台运行；不要结束其他 Python 程序。

6×6 小屏只适合简单图案；文字暂不支持中文，图片不适合展示细节。
本面板不控制全键背光，也不提供 Claude 用量查询。

## Codex 联动的范围与隐私

这是基于本地事件文件的兼容实现，**不是官方 Codex 状态接口**。
它不代表成功完成所有用户目标；绿色只代表观察到本轮任务结束事件。

面板运行时只读扫描最近修改的本地会话文件，解析事件类型、时间和工具调用 ID，
跟随一个用户主任务并显示到键盘上。读取到的 JSON 行可能包含聊天内容；程序不保留聊天正文，
不在网页中显示正文，也不上传会话文件。页面仅显示状态和会话标识末八位。
没有遥测、外部字体、账户登录或云端服务；服务只监听 `127.0.0.1`。

- 自动选择活跃的用户主任务并锁定跟随；后台审核、子任务与其他会话的结束不会抢占当前任务。
- 只有观察到与主任务开始相匹配的结束事件才显示完成；工具步骤成功或失败都不代表整轮任务结束。
- 完成/错误提示约 6 秒消退；5 分钟无相关事件则回到待机，不能据此判定任务结束。
- 部分审批等待没有可观测事件，可能仍显示工作/工具状态。
- 不覆盖其他电脑、云端执行以及不写入本地会话文件的任务。
- Codex 日志格式变化可能影响识别。

## 开发与测试

```sh
DYLD_LIBRARY_PATH="$(brew --prefix hidapi)/lib" .venv/bin/python -m unittest discover -v
```

当前提供 31 项动画、输入验证、主任务事件跟随、连接与启动器测试。测试不要求连接键盘。
发布整理中另提供启动器路径引用测试。软件仍为早期版本，浏览器跨版本兼容和
不同键盘固件尚未充分验证；欢迎提供可复现问题。
